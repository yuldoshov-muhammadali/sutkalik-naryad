Kurs boshlig‘i (admin)

  1. Haftalar → yakshanbani tanlang → Haftani ochish. Hafta: yakshanba 18:00 → yakshanba 18:00.
  2. Sutkani bosing → Tuzish. Sutka: shu kun 18:00 → ertasi 18:00. Sutkalar ketma-ket tuziladi.
  3. Kerak bo‘lsa Almashtirish: ro‘yxatdan nomzod (eng munosibi birinchi) + sabab majburiy (kasal / ta’til / sababli / boshqa). Hammasi jurnalga yoziladi.
  4. Qizil ogohlantirish qolmasa → Tasdiqlash. Tasdiqlangan ro‘yxat o‘zgarmaydi (kerak bo‘lsa “Tasdiqni bekor qilish”, sabab bilan).
  5. PDF yuklab olish yoki Chop etish (rasmiy shakl, A4). Haftalar sahifasida — hafta PDF’i.
  6. Sababli holatlar: kasal / ta’til sanalarini oldindan kiriting — dastur o‘sha kunlarda qo‘ymaydi.
  7. Kursantlar: qo‘shish, tahrirlash, faolsizlantirish (tarix saqlanadi), Excel import.
  8. Statistika: adolat belgisi va qo‘lda tuzatishlar ogohlantirishi; Excel’ga yuklab olish.

Kursant

  1. Manzilni oching, login va kurs boshlig‘i bergan vaqtinchalik parol bilan kiring.
  2. Birinchi kirishda yangi parol qo‘ying (kamida 8 belgi, oddiy bo‘lmasin). Keyin: Menyu → Parol.
  3. Bosh sahifa: keyingi naryadingiz, shu haftada va jami nechta.
  4. Mening tarixim: barcha naryadlaringiz, joylar va lavozimlar bo‘yicha, guruh o‘rtachasi bilan solishtirish.
  5. Tasdiqlangan naryadlar: to‘liq ro‘yxat, PDF yuklab olish va chop etish.
  6. Kasal bo‘lsangiz yoki ta’tilga ketsangiz — kurs boshlig‘iga oldindan ayting.
  7. 5 marta noto‘g‘ri parol → 15 daqiqa blok. Parolni unutsangiz — kurs boshlig‘iga murojaat qiling.

Adolat qanday ta’minlanadi

• Joylar guruhlar o‘rtasida aylanadi: Markaz → 1-NO‘J → 2-NO‘J → 1-Yotoqxona → O‘quv binosi → Patrul. Qizlar alohida (qizlar yotoqxonasi).
• Guruh ichida tanlash tartibi: shu haftada kam turgan → jami kam → o‘tgan safar boshqa joyda → shu joyda kam → uzoqroq dam olgan.
• Kecha navbatda bo‘lgan va sababli yo‘q kursant hech qachon qo‘yilmaydi.
• Adolat belgisi (guruh ichida jami naryadlar farqi): yashil ≤ 1, sariq = 2, qizil ≥ 3.
